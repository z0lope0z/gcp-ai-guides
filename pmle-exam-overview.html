1. The exam at a glance

The Professional Machine Learning Engineer (PMLE) exam tests whether you can choose and operate the right approach and Google Cloud service at each stage of an ML system, for classic predictive ML and for generative AI (gen AI). It's a judgement exam: the guide says coding isn't assessed directly, but you should be able to read Python and SQL snippets.

3. The 2026 renames

In April 2026 Google folded Vertex AI into Gemini Enterprise Agent Platform ("Agent Platform") and renamed Cloud Composer to Managed Service for Apache Airflow. The exam uses the new names; most courses, blogs and code still use the old ones. APIs stayed backward compatible: the Python package is still google-cloud-aiplatform, the API host is still aiplatform.googleapis.com, and the CLI is still gcloud ai and gcloud composer.

4. How to read Google scenario questions

Most questions describe a company, a constraint and a goal, then offer four designs that would all work in some sense. The right one meets the binding constraint with the least custom work.

  1. Find the binding constraint. "Minimal code" or "analysts know SQL"; "lowest latency"; "lowest cost"; "data must not leave the VPC"; "must explain each prediction"; "small labelled dataset"; "fastest time to market"; "existing Spark/Kubeflow investment".
  2. Climb the managed ladder from the bottom and stop at the first rung that meets every requirement.
  3. Move code to the data. Data in BigQuery points to BigQuery ML or a BigQuery-sourced pipeline, not a CSV export.
  4. Prefer managed services (Pipelines over cron scripts, Model Monitoring over hand-built histogram jobs) unless the question rules them out.
  5. Check the ML reasoning even when the service is obvious: leakage, imbalance, the right metric, the right split.
  6. Eliminate the over-engineered and the under-powered. TPU custom training for 10,000 tabular rows is wrong; so is AutoML when the team needs a custom loss.
RungOptionUse when
1Prebuilt API (Vision, Document AI, Translation, Speech)Generic task; standard classes are fine
2BigQuery ML or AutoMLYour labels, tabular or image data, little or no ML code
3Gemini or another Model Garden model: prompt, then ground, then tuneLanguage, documents, multimodal, generation
4Managed custom training on Agent PlatformYour architecture, loss, framework or scale
5Self-managed on GKE, Ray or Compute EngineExisting platform, special scheduling or control the managed path can't give
"API, SQL, Auto, Gemini, Custom, DIY." From least to most effort. The exam usually wants the lowest rung that satisfies every stated requirement.
"Technically correct but more work" is the most common wrong answer. When two answers both work, choose the more managed one that keeps data where it is and meets the constraint.

Multiple-select questions

  • The stem says how many to pick ("Choose two"). Each chosen option must be independently true and relevant.
  • Watch for one option that is true but doesn't address the stated problem.

9. Common gotchas in one list

  1. Old and new names are the same product: Vertex AI = Agent Platform; Composer = Managed Airflow; DLP = Sensitive Data Protection.
  2. Lowest rung that meets every requirement; extra custom work is the usual wrong answer.
  3. Keep the data where it is: BigQuery data suggests BigQuery ML or BigQuery-sourced training.
  4. Check the fundamentals inside cloud stories: leakage, imbalance, metric choice, time-based splits.
  5. Fresh facts need grounding, not tuning.
  6. Managed beats DIY unless the stem names an existing platform or a requirement only DIY meets.
  7. Multiple select: every chosen option must be true and address the problem.
  8. Security words change the answer: "no public internet", "exfiltration", "PII", "CMEK".
