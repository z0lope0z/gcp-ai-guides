# Google Cloud Professional Machine Learning Engineer study guides

Interactive, self-contained HTML study guides for the Google Cloud Professional
Machine Learning Engineer (PMLE) certification, following the exam guide dated
June 1, 2026. Open `index.html` in a browser; there's no build step.

## Guides

- [PMLE: the complete guide](pmle-mastery.html): all six exam sections, five
  hands-on labs, a classification metrics calculator, a serving capacity
  calculator, a "which service?" chooser, sample outputs, scenarios, a
  searchable reference, flashcards, common gotchas and a practice quiz.

## Format

Guides follow [FORMAT_PROMPT.md](FORMAT_PROMPT.md), the formatting prompt derived
from the NVIDIA NCP-AII study guides. Use it to add guides here or to start a
guide set for another certification.

## Note on product names

In 2026 Google renamed Vertex AI to Gemini Enterprise Agent Platform and Cloud
Composer to Managed Service for Apache Airflow. The guides use the new names and
map them to the old ones you'll still see in courses and code.
